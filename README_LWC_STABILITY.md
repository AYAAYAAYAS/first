# LWC 判别／稳定表征：四组配对实验

入口为 `run_lwc_stability.py`；模型为 `lwc_stability_model.py`。原 DGGN 仓库没有修改。这是借鉴稳定参考思路的新实验，不是原论文逐式复现。

## 四组的精确定义

| 组别 | 最终判别 | 支持适配时稳定分支 | 特征交流 |
|---|---|---|---|
| single | 判别分支马氏距离 | 不使用 | 无 |
| parallel | 判别／稳定分支各自马氏距离得分的平均 | 冻结 | 无，只有末端得分融合 |
| frozen_exchange | 交流后判别分支与稳定分支马氏距离得分平均 | 整条路径冻结，包含自己的 LWC | 单向门控残差交叉注意力 |
| trainable_exchange | 同上一组 | 参与更新 | 同上一组 |

末端平均得分不能与“完全没有融合”混为一谈；它是用来区分双模型集成收益与特征交流收益的对照。第三、四组使用逐参数一致的源模型，区别只发生在支持适配阶段。第四组较小的稳定分支学习率是配置的一部分，因此该比较衡量的是“冻结与小学习率更新”两种策略。

## 输入与网络

只用 LASPI 振动通道。保留 25,600 Hz 原始采样，窗口 8,192 点（0.32 秒），逐窗去均值／标准差归一化。输入来自已有原始波形缓存，不重新改写原 CSV。

沿用此前工程实际使用的可学习 LoG／Mexican-hat 形式 `(1-u²)exp(-u²/2)`，学习尺度、位移、幅值。它不是振荡衰减 Laplace 小波，也不是电蚀物理方程。

每条分支有独立 LWC。保留有符号响应及局部能量形成一维序列，用对数局部能量形成二维尺度—时间图。响应先按 16 点局部聚合；1D、2D CNN 再各压缩时间方向四倍，最终分成 16 个时间 token。保留原始采样不等于网络内部不压缩，更不等于完全没有信息损失。

二维图纵轴是小波核编号，不是线性频率 Hz。查看实际核的频率响应，才能知道滤波器覆盖的频段。两个 CNN 的 token 拼接后得到 64 维 token；四个 16 维成分分支及 BCE 结构监督输出 64 维归一化特征。四种成分是齿轮表面损伤、半断齿、内圈、外圈，不代表已经实现因果分离。

## 三个训练阶段

1. 共同源预训练：60 轮，每轮 15 次更新。判别、稳定分支都用成分 BCE 和跨转速五类马氏分类训练；稳定分支另外缩小同类跨转速中心距离。每类每次选择同载荷、两个不同标称速度组，各 4 个窗口。类别分类损失用于防止简单坍缩。
2. 源模型衔接：单分支、双分支无交流、冻结参考交流各训练 20 轮，每轮 15 次更新，稳定分支均冻结。只用源基类验证 NLL 选权重。第四组复制第三组模型。第一组从共同预训练的判别分支出发，不是独立从随机初始化重训的纯单网络基准。
3. K-shot 适配：只做 1／5／10-shot；每个新类 K 个窗口来自 K 个不同源 CSV，未使用目标工况标签。每次同时回放 5 个基类各 8 个窗口，进行 30 次更新。判别分支的 LWC 和两个 CNN 第一块冻结，后续 CNN、成分头参与更新。第三组整条稳定参考冻结；第四组稳定参考（含其自己的 LWC）以较小学习率更新。

适配目标 = 基类／新类均衡成分 BCE + 与最终得分形式一致的马氏交叉熵 + 源基类特征保持项。第四组的稳定分支额外受到同类跨速度中心约束及回放保持项。原型参考视图不反传；多个支持时用留一原型，1-shot 则是同一允许样本的加噪视图，不能当成第二个独立样本。训练协方差来自当次基类回放，测试来自固定 100 个基类记忆；两者估计方法一致，但样本集合和估计值不同。

残差信息交流采用 `D_tokens + gate * Attention(D_tokens, S_tokens, S_tokens)`。门控上限 0.5，初始约 0.06；输出仍通过原来的四个成分分支。稳定分支不接收判别分支的反向特征输入。

## 公平性和边界

- 沿用按原 CSV 的 70%／20%／10% 划分和目标工况隔离；全部已知完全重复 CSV 排除。保持五基类、两个复合新类。
- 四组相同划分、基类记忆、支持 ID、回放抽样种子、噪声种子、源衔接更新数及适配更新数。独立双分支需要更多计算量，并不具有相同 FLOPs。
- 每基类固定 20 个源训练 CSV 各取一个窗口，形成 100 个记忆样本；所有组相同。
- 验证文件进一步隔离成模型选择、温度标定、策略预留三组。本实验只做分类与温度标定，不训练拒判／逐窗策略。温度标定只见源基类，对复合新类和目标工况的校准效果不作保证。
- 相同故障不同标称转速的约束只能称为跨工况稳定性，不证明因果性或时间长期稳定。来源于同一个试件的多 CSV 仍可能相关。
- 当前没有 BNN、物理损失或强化学习，避免掩盖四组结构比较。不能用这里的实验直接支持电蚀机理或退化预测结论。

配置 JSON 可改：`source_epochs` 源预训练轮数、`exchange_epochs` 衔接轮数、`steps_per_epoch` 每轮更新数、`adapt_steps` 支持适配次数；`source_lr`／`wavelet_lr` 源学习率、`adapt_lr` 判别适配率、`stable_adapt_lr`／`stable_wavelet_adapt_lr` 稳定适配率；`shrinkage` 协方差收缩系数；`stability_weight` 稳定约束权重；`replay_distill_weight` 保持项权重。

自动使用 CUDA，终端有阶段进度条和逐任务基类／新类 F1 打印。已存在输出目录会自动换名，不覆盖。中断后用原配置和打印的结果目录续跑：

```powershell
& 'D:\python_project\.venv\Scripts\python.exe' -B run_lwc_stability.py --config lwc_stability_full.json --resume 'H:\keyan\9_23\LASPI_GFSL\results\lwc_stability_full_20261017'
```

已完成的源阶段和任务会跳过；未完成的源阶段会从该阶段起点重做，不是优化器逐步断点恢复。修改训练算法后应使用新输出目录，不应沿用旧结果。

完整配置训练结束自动打开中文窗口；预实验默认不弹窗，可手动打开。替换成终端实际输出目录：

窗口显示四组 F1 对照、内外圈成分 F1、稳定参数漂移、首个 5-shot 任务混淆矩阵、滤波器实际 Hz 频响与尺度—时间响应图。图片不自动保存；用窗口工具栏保存。混淆矩阵为单次支持集示例，不等于全部重复平均。

结果主表为 `summary.csv`／`summary.json`，逐任务指标为 `metrics.json`；每工况种子子目录有完整划分、支持 ID、冻结审计、源训练历史与示例模型。先看复合新类 F1 是否提升，再看五基类是否退化，不能只挑最高准确率。

额外诊断脚本只评估首个 5-shot 支持集，分别报告适配前后只在五基类候选中分类的效果、七类竞争时基类误入新类比例，以及源验证／目标工况的成分概率。该诊断使用测试标签计算指标，不参与训练或选模型；不能据此反复调参后仍把同一测试集当作独立证据。

## 2026-10-17 已完成预实验

目录 `results/lwc_stability_20261017`：25 Hz 空载、种子 42、每个 shot 5 次支持抽样，共 60 个适配任务，GTX 1650 CUDA，运行约 384 秒。三个结构检查通过，60 个结果的支持／冻结／隔离审计通过，四个中文图窗口已在不写图文件的方式下完成渲染检查。

七类 Macro-F1（%），均为 5 个支持集的平均：

| 组别 | 1-shot | 5-shot | 10-shot |
|---|---:|---:|---:|
| 单判别 | 34.82 | 37.48 | 40.89 |
| 双分支无特征交流 | 41.05 | 51.49 | 54.23 |
| 冻结参考＋交流 | 41.16 | 51.79 | 54.65 |
| 更新参考＋交流 | 40.79 | 52.14 | 54.73 |

此结果尚不能支持论文中的机制有效性结论：

1. 双分支得分融合优于单判别；但没有无稳定约束的普通双编码器集成对照，因此不能把全部收益归因于跨转速稳定约束。
2. 第三组比第二组只提高 0.11／0.30／0.42 个百分点，未检验统计显著性；第四组和第三组差异更小，没有证据证明冻结策略占优。
3. 所有任务中，判别成分头的内、外圈成分 F1 在 0.5 阈值下均为 0。首个 5-shot 任务里，源验证的内圈阳性／阴性均值概率约 0.223／0.224，外圈约 0.222／0.221，说明不能只靠降低阈值宣称成分已经被分离。距离分类仍可利用细微嵌入差异，并不意味着 BCE 语义头有效。
4. 首个 5-shot 任务，第三组仅五基类候选时目标 F1 从适配前 62.57% 到适配后 66.67%；加入复合候选后约 25.8% 基类样本误入新类。表征迁移和类别竞争都需要处理，不能只归咎于适配。
5. 源基类温度标定在 1／5-shot 目标工况总体恶化 ECE，10-shot 则有改善；不能把源校准当成目标工况可信保证。

这些是一个工况、一个种子的诊断结果，不是完整跨工况结论。完整配置尚未运行。建议先在源验证集检查 BCE 阳／阴性分离、成分损失与度量损失的梯度比例，再考虑完整运行；不要依据本次目标结果反复调参并把该目标继续当作最终独立测试集。
